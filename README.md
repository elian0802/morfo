# Morfo

Página de repaso de Morfología I: bases anatómicas y osteología, cráneo, esqueleto (tórax y miembros) y articulaciones.

Incluye:
- Resumen por unidad con tablas comparativas y mnemotecnias
- 57 tarjetas de estudio (flashcards) con seguimiento de las dominadas
- Autoexamen de 58 preguntas de opción múltiple con explicación

Para usarla, abre `index.html` en el navegador.
